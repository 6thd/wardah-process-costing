# لوحة Gemini المالية الذكية - التكامل مع وردة ERP

## نظرة عامة

تم تحسين لوحة Gemini المالية لتعمل تلقائياً مع البيانات الحقيقية من نظام وردة ERP. توفر اللوحة تحليلاً مالياً متقدماً يشمل:

- ✅ **تحليل الربح والخسارة** من البيانات الحقيقية
- ✅ **حساب نقطة التعادل** (Break-Even Point)
- ✅ **هامش الأمان** (Margin of Safety)
- ✅ **هامش المساهمة** (Contribution Margin)
- ✅ **مزامنة تلقائية** مع قاعدة البيانات
- ✅ **تحليل شهري** للبيانات المالية

### 3. البيانات المعروضة

#### KPIs الرئيسية:
- **إجمالي المبيعات**: من قيود اليومية (حسابات الإيرادات)
- **صافي الربح**: الإيرادات - COGS - المصروفات
- **نقطة التعادل**: المبيعات المطلوبة لتغطية التكاليف
- **هامش المساهمة**: نسبة المساهمة في تغطية التكاليف

#### تحليل نقطة التعادل:
- **نقطة التعادل (مبيعات)**: المبلغ المطلوب لتغطية التكاليف
- **هامش الأمان**: الفرق بين المبيعات الحالية ونقطة التعادل
- **التكاليف الثابتة**: التكاليف التي لا تتغير مع حجم المبيعات

## الحسابات المالية

### نقطة التعادل (Break-Even Point)
```
نقطة التعادل = التكاليف الثابتة / هامش المساهمة
```

### هامش الأمان (Margin of Safety)
```
هامش الأمان = المبيعات الحالية - نقطة التعادل
نسبة هامش الأمان = (هامش الأمان / المبيعات الحالية) × 100
```

### هامش المساهمة (Contribution Margin)
```
هامش المساهمة = المبيعات - التكاليف المتغيرة
نسبة هامش المساهمة = (هامش المساهمة / المبيعات) × 100
```
