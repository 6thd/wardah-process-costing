**المبدأ:** لا مرحلة «منتهية» بادعاء. كل معيار هنا **قابل للفحص آليًا** أو مقترن
بأثر محفوظ (Artifact). معيار لا يمكن إثباته بمخرج محفوظ ليس معيارًا.

## 🎯 هدف الـ90 يومًا — بصياغة قابلة للقياس

الصياغة الأصلية: *«تشغيل مصنع بلاستيك افتراضي 90 يومًا، 15 مستخدمًا، إغلاق شهري
كامل، بدون كسر المحاسبة أو المخزون أو التكلفة.»*

تُترجم إلى معايير لا تحتمل التأويل:

| # | المعيار | العتبة |
|---|---|---|
| G-1 | أيام محاكاة متصلة بلا إعادة تهيئة يدوية | **≥ 90** |
| G-2 | ممثلون نشطون بأدوار حقيقية متمايزة | **15**، منهم ≤ 2 org admin |
| G-3 | إقفالات شهرية كاملة عبر `SC-CLOSE-01` | **3** |
| G-4 | فشل `S0` عبر التشغيلة كاملة | **0** |
| G-5 | فشل `S1` عبر التشغيلة كاملة | **0** |
| G-6 | `INV-GL-05` (ميزان المراجعة) عند كل إقفال | **0 انحراف** ≥ 0.01 |
| G-7 | `INV-INV-05` (الدفتر الفرعي × العام) عند كل إقفال | متوازن ضمن التسامح المعايَر |
| G-8 | `INV-INV-01` عند كل نقطة سكون | **0 صف** |
| G-9 | `INV-SEC-01` تسرّب مستأجرين | **0 صف** طوال التشغيلة |
| G-10 | ثوابت حوكمة المختبر `INV-LAB-01…04` | **خضراء طوال التشغيلة** |
| G-11 | سيناريوهات السباق الثمانية منفَّذة داخل الـ90 يومًا لا كتمرين منفصل | مسجَّلة في الجدول الزمني |
| G-12 | كل اكتشاف `S0`/`S1` أثناء الطريق له اختبار قبول حتمي مدموج | ملفات `acceptance_*` |

**G-10 شرط صلاحية لا شرط أداء:** تشغيلة خضراء خرقت حوكمتها الذاتية نتيجتها
باطلة، لا ناجحة. تُعاد لا تُقبل.

**ما لا يثبته اجتياز الهدف:** لا يثبت جاهزية إنتاجية، ولا صحة أرقام أداء على عتاد
الإنتاج، ولا يغني عن E2E أو مراجعة أمنية. يثبت شيئًا واحدًا محددًا: **أن عقود
Wardah التشغيلية تصمد 90 يومًا من الاستخدام المتزامن الواقعي دون كسر ثابت محاسبي
أو مخزوني معلوم.** هذا كثير، وليس كل شيء.
